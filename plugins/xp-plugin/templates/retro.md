## Retro skeleton — fill this in yourself, then propose the diff

A learning that changes nothing executable is not recorded. Every item below
either becomes a diff to constraints.md / config.yml / a charter, or it is
archived. The narrative is PRESENTED to the human at close, never just filed.

1. What did the process CATCH that we would otherwise have shipped? Name the
   mechanism, not the finding.
2. What did it MISS, and which mechanism should have caught it?
3. Which rule earned its place this sprint, and which one cost more than it
   returned? The second one is what the first one displaces.
4. The proposed diff: file, line, before → after.
