## Sprint retrospective

Present the narrative to the human and keep it with the sprint's external data.

1. What outcome shipped, and what remains unresolved?
2. What did independent judgment catch or miss? Cite the evidence.
3. Which tradeoffs earned their cost, and which did not?
4. Which executable changes should the lead review before shipping or defer?

Narrative discovery needs no code change. An executable proposal is separate work;
calling it a retro never exempts it from review.
